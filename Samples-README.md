# CoachHoopsAI – Regression Samples

This folder contains regression samples for the endpoint:

POST /api/game-analysis

These samples are used to:
- verify rule behavior
- validate diagnostics consistency
- ensure validation errors are returned correctly
- detect unintended changes when rules or thresholds evolve

All samples are designed for **manual execution** via Swagger or Postman.

---

## How to use

1. Run `CoachHoopsAI.Api`
2. Open Swagger UI (`/swagger`)
3. POST each JSON file to `/api/game-analysis`
4. Compare the response against the expected behavior listed below

Important:
- Suggestions are currently generated by a fake AI client, so **text may change**
- ProblemTags and Diagnostics are deterministic and should remain stable unless rules change

---

## Diagnostics Expectations

All **valid samples** should return a `diagnostics` object containing:

- PointsDiff
- TurnoversDiff
- OffensiveReboundsDiff
- DefensiveReboundsDiff
- TeamFieldGoalPercentage
- OpponentFieldGoalPercentage
- FieldGoalPctDiff
- ThreePointPctDiff
- ThreePointAttemptsDiff
- FoulsDiff

Diagnostics must be consistent with the input stats and should clearly explain why ProblemTags were triggered.

---

## Rule Stability Note

ProblemTags are generated by deterministic rules (StatRulesEngine).

If you change:
- thresholds
- comparisons
- rule definitions

You **must** update:
- expected tags in this README
- possibly add new regression samples

Keeping this file accurate is critical for maintaining confidence in rule evolution.
