CoachHoopsAI notes

- A request flow through the system

1. Client → API

	POST /api/game-analysis

	Body: AnalyzeGameRequest (stats, level, coach notes)

2. API → Application

	Controller maps request → GameAnalysisInput

	Calls IGameAnalysisService.AnalyzeAsync(input)

3. Application → Domain

	GameAnalysisService calls _rulesEngine.Evaluate(team, opponent)

	Gets list of ProblemTags

4. Application → Infrastructure (AI)

	GameAnalysisService calls _llmClient.GetSuggestionsAsync(input, tags)

	OpenAiSuggestionClient builds prompt, sends to AI API, parses result

5. Application → API

	GameAnalysisService returns GameAnalysisResult

	Controller maps to AnalyzeGameResponse DTO

	Returns JSON to the client
