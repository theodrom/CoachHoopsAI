# Samples

The /samples folder contains regression payloads.

## Purpose

- Validate rule behavior
- Ensure diagnostics consistency
- Catch regressions
- Verify validation errors

## Sample Coverage

- Turnovers and transition
- Hot three-point shooting
- Defensive rebounding
- Shooting inefficiency
- EasyBasket fundamentals
- Interior defense
- Too many threes
- Validation failure

Samples are authoritative for expected behavior.
